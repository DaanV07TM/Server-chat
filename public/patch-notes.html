Release history

What's new

A dated record of security improvements, interface fixes and features shipped to Server Chat. Newest changes appear first.

29 October 2026
Security & UI
Released

Local login bot friction and interface cleanup

  • Added a lightweight server-issued proof-of-work check before temporary account creation and password-based user/admin logins. A successful proof approves the originating IP address for 10 minutes, so repeated actions from that same address can reuse the approval until it expires.
  • The server validates that each challenge is correct, belongs to the current connection, has not expired and has not been used before. The browser performs approximately 4,096 SHA-256 hashes on average, with visible progress and a timeout/error message if the registration or login flow stalls.
  • Added a custom Server Chat “Verify I’m not a bot” checkbox for both account creation and login. Checking it runs the existing server-verified proof-of-work challenge and shows a short approval screen only after the server confirms the network.
  • The checkbox remains approved for the same 10-minute server window and clears itself when that approval expires. The check is still validated on the server and is not treated as proof that a visitor is definitely human.
  • The login flow now shows progress and a clear error when the security check fails, expires or loses its connection.
  • Admin command buttons explicitly use type="button" to avoid accidental form submissions.
  • Removed unused empty-state element IDs to keep the DOM cleaner.
  • Made the sidebar connection indicator follow the real socket connection state instead of always showing green as if the server were connected.
  • Improved service-worker navigation caching so previously cached legal and patch-note pages can be opened offline.
  • Added this page so changes have a visible date and explanation.

The proof-of-work check raises the cost of automated attempts; it is not a perfect human detector. Server-side verification and login rate limits remain important.

28 October 2026
Security
Released

Terms, privacy and traffic controls

  • Added a Terms of Service and Privacy Notice, with server-side consent checks during temporary account creation.
  • Added in-memory limits for rapid API requests, Socket.IO events and connection bursts, with temporary IP blocks.
  • Prepared optional Cloudflare Turnstile registration verification; live verification requires its site and secret keys in the hosting environment.
  • Added documentation explaining temporary IP processing and the limitations of application-level controls.
27 October 2026
Interface & chat
Released

Ubuntu COSMIC visual refresh

  • Introduced the aubergine sidebar, desktop-style quick-launch area and responsive channel navigation.
  • Added Ubuntu, Arctic Blue, Matrix Green and Rose Quartz accent palettes alongside light and dark themes.
  • Expanded the public and admin live server status views.
  • Added built-in stickers and slash-command helpers, including polls and quizzes.
Security note: these notes describe application behaviour, not a guarantee against every attack. A large network-level DDoS attack requires protection from the hosting or edge provider. The legal notice also needs the operator's real contact details before public use.
